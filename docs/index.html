WAG-046

Controlled Context Intervention — Calibration

New invariant: Predictive context differences are not causal proof. Freeze the experiment before testing, vary one controlled feature, and preserve all observations.

Test model: fixed arm margins and a one-sided association alternative. Synthetic result: 12/12 versus 6/12; p = 0.006865. Proper randomization, independent reference evidence, noninterference, and sampling validity remain prerequisites for causal interpretation.
