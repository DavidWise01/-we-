# RSI-018 — Memory through loss
RSI-017 extension with three distinct local SQLite replica paths. Explicit replication verifies original bytes against current signed Merkle root. Recovery verifies candidate bytes against the current root and indexed inclusion path, restores only missing or invalid raw records, and atomically records the damaged bytes and source in a repair ledger. No new root is created. 68 local tests passed (12 new, 56 inherited). Replication is explicit per record and not atomic across destinations. No authenticated delivery receipt, remote independence, external freshness anchor, durable HOLD, index recovery, or physical power loss test. Replica endpoints are not witnesses. Synthetic signatures and same-host replicas remain limitations. Next: durable replication outbox, authenticated delivery and reconciliation of partial writes.
