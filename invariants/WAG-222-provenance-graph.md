# WAG-222 — Recursive ancestry, aliases and abstention
.dlw

WAG-221's root-name comparison becomes directed provenance-graph traversal. Nodes have zero or more parents; acquisition roots must be explicitly marked root:true, and every traversed node requires verified:true. Alias edges resolve to their target; a broken edge, unverified node, rootless terminal or cycle is UNKNOWN_PROVENANCE, never independent corroboration. Once traversed, common root ancestry collapses purported independent witnesses to a single acquisition ancestry. Distinct roots and at least 0.96 binary slot agreement qualify as two synthetic acquisition witnesses. Disagreement requires independent roots and less than 0.96 agreement.

320 synthetic cases, 61440 paired slot comparisons. Results: distinct_verified: 32/32 expected, 0 unexpected, unknown 0, shared 0, independent 32, disagree 0; naive independent false 0; shared_direct: 32/32 expected, 0 unexpected, unknown 0, shared 32, independent 0, disagree 0; naive independent false 32; shared_deep: 32/32 expected, 0 unexpected, unknown 0, shared 32, independent 0, disagree 0; naive independent false 32; alias_shared: 32/32 expected, 0 unexpected, unknown 0, shared 32, independent 0, disagree 0; naive independent false 32; unverified_root: 32/32 expected, 0 unexpected, unknown 32, shared 0, independent 0, disagree 0; naive independent false 32; broken_link: 32/32 expected, 0 unexpected, unknown 32, shared 0, independent 0, disagree 0; naive independent false 32; cycle: 32/32 expected, 0 unexpected, unknown 32, shared 0, independent 0, disagree 0; naive independent false 32; independent_disagree: 32/32 expected, 0 unexpected, unknown 0, shared 0, independent 0, disagree 32; naive independent false 0; forged_alias: 32/32 expected, 0 unexpected, unknown 0, shared 32, independent 0, disagree 0; naive independent false 32; unverified_distinct: 32/32 expected, 0 unexpected, unknown 32, shared 0, independent 0, disagree 0; naive independent false 32. A label-only baseline falsely accepted 256 agreements as independent across the adversarial families.

Caution: 'verified:true' is a simulator-controlled flag, not cryptographic verification. No second external sensor or hardware attestations were used. This is graph-logic testing, not empirical evidence of independent acquisition. A malicious actor able to alter the graph or fake proof flags may still defeat the procedure. 32 seeded cases per family have limited fixture diversity, and sample observations derive from one common target generator.

Next natural bound WAG-223: tamper-evident evidence packets, signed graph commitments, trust-root governance, explicit threat model and counterexamples from colluding signers. Append-only records should remain reproducible and preserve shared ancestry.
