# WAG-101 — Reviewer control ancestry and external succession review
A pinned external test key signs a complete declared DAG scoped to the epoch, root, nonce, candidate, keys and controllers. Both surviving reviewers must sign the same snapshot. Reject unknown nodes, cycles, shared transitive control (including retired W1 and external authority), invalid signatures, stale scope, missing reviews and repeat acceptance within a process. Preserve submitted evidence in a hash-linked in-memory audit. 24 local regression tests. This gate grants eligibility only, not rotation or fresh quorum certification. It assumes the external key truthfully attests the complete graph; it does not authenticate real ownership, hidden links, durable replay state or distributed consensus. Conservative policy rejects any common control ancestor.
