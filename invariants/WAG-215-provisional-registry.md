# WAG-215 — Reversible provisional component registry
.dlw

WAG-215 extends WAG-214's three-window inference with an append-only event log per synthetic stream. Original components are ESTABLISHED on window 0, new candidates RESERVED on window 1, surviving candidates QUALIFIED on window 2, unsupported candidates EXPIRED, old components that the middle-window model omits either PERSISTED or RELEASED depending on third-window evidence. UNRESOLVED records the absence of an identifiable middle-window model. Replacement ancestry is assigned only when exactly one original period was absent from the new candidate set; otherwise null. Component event IDs are scoped to each experiment run, not globally collision-proof.

368640 observation-slot evaluations across 640 synthetic cases, 3392 ledger events, 640 replay checks and 448 rejected deliberately illegal terminal transitions. Results: stable: correct 64, wrong 0, unknown 0, reserved 0, expired 0; jitterB: correct 62, wrong 2, unknown 0, reserved 0, expired 2; shiftB: correct 64, wrong 0, unknown 0, reserved 0, expired 0; replace: correct 64, wrong 0, unknown 0, reserved 64, expired 0; ephemeral: correct 64, wrong 0, unknown 0, reserved 64, expired 64; dropA: correct 64, wrong 0, unknown 0, reserved 0, expired 0; dropB: correct 64, wrong 0, unknown 0, reserved 0, expired 0; bothDrop: correct 64, wrong 0, unknown 0, reserved 0, expired 0; mixedTransient: correct 64, wrong 0, unknown 0, reserved 0, expired 0; harmonic: correct 0, wrong 0, unknown 64, reserved 0, expired 0.

64 genuine replacement births are qualified and 64 ephemeral births expire; two actually persistent jittered components expire incorrectly. Harmonic pairs remain unknown, and no claims of out-of-family generalization are made. Ledger records are append-only within the run, but are plain JSON objects, not cryptographically immutable or tamper-evident. No live deployment, true source-independent witness, signed polarity symmetry, physical resonance or runtime latency is proven.
