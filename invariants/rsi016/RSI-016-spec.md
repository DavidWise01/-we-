# RSI-016 — Continuous memory
RSI-015 selective recall with incremental dyadic Merkle index updates. Each signed append commits raw records, new nodes, frontier, journal and index marker atomically. Existing databases require explicit verified migration before append. Recall still verifies inclusion against the signed root; index readiness is enforced on append, not separately on recall. 44 local tests passed (10 new, 34 inherited), including 257 individually signed appends and subsequent recall of every record. Insertion creates 2n-popcount(n) nodes cumulatively; one append adds 1 plus the number of trailing ones in the previous count. Cache keys remain tied to the exact checkpoint, so cache reuse across growth is not implemented. Synthetic witnesses, same-host rollback, actual power loss, and ERSE scheduler/energy integration remain limitations. Next: authenticated cache rebasing across growing roots.
