# WAG-060 — Monotonic Checkpoint Extension and Trust Restoration

Status: instantiated and tested locally on 2026-11-15. 24/24 unittest checks passed; browser-renderable WAG-060 SVG illustration committed to docs/index.html. The synthetic demonstration returned RESTORED and a valid five-record SHA-256 chain.

## Natural invariant
RESTORE_TRUST => VALID_FROZEN_CHECKPOINT AND AUTHENTICATED_EXTENSION AND FRESH_HEAD AND NO_KNOWN_FORK.

A network reconnect is not evidence that an observed new history preserves what a witness verified before partition. Preserve the exact frozen pre-partition head until a signed, same-log, monotonic extension has been independently checked. Rollback and stale heads cause HOLD; conflicting histories cause QUARANTINE.

## Reference algorithm
- Freeze an Ed25519-signed log head (log ID, fully disclosed ordered leaves, Merkle root, logical epoch).
- Partition event moves operational status from CURRENT to HOLD_PARTITION, preserving the exact original root.
- During reconnection verify the new head's signature and named log identity.
- Reject a shorter tree or an older logical epoch with HOLD_ROLLBACK.
- Compare the entire prior leaf sequence to the prefix of the new disclosed leaf sequence; a mismatch leads to QUARANTINE_FORK.
- Check any known unresolved fork before trust restoration.
- Reject stale heads according to a prespecified maximum-age window, returning HOLD_STALE.
- Only then replace the frozen operational checkpoint with the new head and append a RESTORED event.
- Preserve every decision and original observation in a SHA-256-linked single-writer log.

## Executed deterministic example
Frozen H0: [a,b,c], epoch 10. Network partition recorded. Reconnect with signed H1: [a,b,c,d], epoch 13, observed at logical time 14, max age 5. Exact prefix matches, signature verifies, no known fork. Decision RESTORED. Five SHA-256-linked records verify.

## Scope and limitations
Locally generated Ed25519 keys are not externally authenticated operator identities. This code verifies the complete disclosed leaf list using a simple binary Merkle-root routine, **not** an RFC6962 compact consistency proof. Its epoch and freshness checks use caller-provided integer ticks rather than trusted timestamps; public gossip, quorum coverage, true network partitions, durable external anchors and concurrent writes are out of scope. The demonstration does not establish trust in a real deployed transparency log. The JPG dashboard contains decorative numerical figures and claimed statuses that were not generated by the test and should not be treated as measurements.

## Next Natural Invariant — WAG-061: Anchored Quorum Re-Certification
A monotonic history extension can still originate from one compromised log operator. Bind restored trust to an authenticated checkpoint anchor and an independently witnessed, fresh quorum; enforce source ancestry separation and keep historical status distinct from operational status. On missing attestation remain HOLD, on equivocation QUARANTINE, and never reuse a historical receipt as evidence of a new epoch.
