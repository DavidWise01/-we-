# WAG-212 — Component persistence and phase reacquisition
.dlw

A single 384-slot binary observation stream contains two proposed generators. The first 192 slots learn two components by greedy ±1 one-to-one event matching (single candidate periods 7–46, each with best phase; pair must improve training F1 by 0.1 and have F1≥0.8). The second 192 slots test each learned component's predicted event precision. Strict policy requires precision ≥0.7 at its old phase; elastic policy can search a ±3 phase offset and keep the same period, with the same threshold. There is no ability yet to discover a new period in the second half.

Executed 393216 observation slots across 8 conditions × 2 policies × 4 base periods × 16 seeds. Results: stable/strict: 64 correct, 0 wrong, 0 unknown, 64 pair-trained; stable/elastic: 64 correct, 0 wrong, 0 unknown, 64 pair-trained; jitterB/strict: 64 correct, 0 wrong, 0 unknown, 64 pair-trained; jitterB/elastic: 64 correct, 0 wrong, 0 unknown, 64 pair-trained; shiftB/strict: 0 correct, 64 wrong, 0 unknown, 64 pair-trained; shiftB/elastic: 64 correct, 0 wrong, 0 unknown, 64 pair-trained; dropA/strict: 64 correct, 0 wrong, 0 unknown, 64 pair-trained; dropA/elastic: 64 correct, 0 wrong, 0 unknown, 64 pair-trained; dropB/strict: 64 correct, 0 wrong, 0 unknown, 64 pair-trained; dropB/elastic: 64 correct, 0 wrong, 0 unknown, 64 pair-trained; bothDrop/strict: 64 correct, 0 wrong, 0 unknown, 64 pair-trained; bothDrop/elastic: 64 correct, 0 wrong, 0 unknown, 64 pair-trained; driftB/strict: 0 correct, 64 wrong, 0 unknown, 64 pair-trained; driftB/elastic: 0 correct, 64 wrong, 0 unknown, 64 pair-trained; harmonic/strict: 0 correct, 0 wrong, 64 unknown, 0 pair-trained; harmonic/elastic: 0 correct, 0 wrong, 64 unknown, 0 pair-trained.

Phase shifts are fully recovered under the elastic rule on these designed fixtures, but a real period change is not recovered and harmonic pairs are not separable by training. A no-components ground truth is 'correct' when nothing is retained; this is not equivalent to a successful discovered two-component model. The fixtures include repeated exact patterns across seeds, so cases are not independent samples. Signal polarity inversion is not modeled, and these are neither mirrored-polartity checks nor biological/physical frequency measurements. No runtime latency benchmark has been performed.

Preserve the failures: counterexamples.json records 32 exact binary inputs, observed events, learned components, and mistaken classifications. Next WAG-213: birth of new frequencies, harmonic ancestry, and distinguishing a genuine period replacement from a phase shift.
