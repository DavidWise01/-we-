# G90 execution handoff · .dlw

Prerequisites: Linux, bash, Git, rustup, network access to GitHub and crates.io, sufficient disk space. Inspect the runner before executing. Run `bash g90-handoff.sh` in a writable directory. It creates a new unique directory, checks out 8b7bca2810ca1fa6901c7120ac0cd4d41e91aaa0, resolves dependencies and captures compiler and four selected test suites. It stops on bootstrap or compilation failure. Return the evidence directory including failures and SHA256SUMS; review logs for sensitive data before sharing. The lockfile is newly resolved, not historically pinned. No signature or independent custody is implied. Do not treat a successful exit as operational authority. The G89 ZIP is separate and contains environmental observations, not Rust source.
